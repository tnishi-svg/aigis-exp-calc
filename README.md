# 千年戦争アイギス 強化合成計算機

キャラ 1 体のレベル上げに必要な素材の組み合わせを求める、自分専用の Web アプリ(PWA)です。スマホで使うことを最優先にしています。

## 確定した仕様

### 入力

- レアリティ: アイアン、ブロンズ、シルバー、ゴールド、プラチナ、ブラック、サファイア
- 覚醒段階: 覚醒前、第一覚醒、第二覚醒(アイアン、ブロンズ、シルバーは覚醒前のみ)
- 現在の Lv
- 「次のレベルまで」の値(ゲーム画面に出る値。空欄なら現在の Lv ちょうどとして扱う)
- 目標 Lv(レアリティと覚醒段階から決まる上限 Lv まで)

ゲーム内では累計経験値が見えないので、累計経験値は次の式で逆算します。

```
累計経験値 = 現在 Lv の累計必要経験値 + (そのレベルの必要経験値 - 「次のレベルまで」)
```

「次のレベルまで」がそのレベルの必要経験値を超えていたら、エラーにします。

### 上限 Lv

サファイアはレアリティです。必要経験値はプラチナと同じで、上限 Lv だけが違います。

| レアリティ | 覚醒前 | 第一覚醒後 | 第二覚醒後 |
|---|---|---|---|
| アイアン | 40 | - | - |
| ブロンズ | 50 | - | - |
| シルバー | 55 | - | - |
| ゴールド | 60 | 80 | 99 |
| プラチナ | 70 | 90 | 99 |
| ブラック | 80 | 99 | 99 |
| サファイア | 65 | 85 | 99 |

### 出力

どの素材を何個、何回に分けて合成するかの手順を出します。各合成の後の Lv と「次のレベルまで」も出すので、ゲーム画面と照らし合わせて確認できます。あわせて、合成回数、ゴールド合計、余り経験値を出します。

### 最適化の優先順位

1. 余り経験値を最小にする。
2. 合成回数を最小にする。
3. ゴールド合計を最小にする。

- 1 回の合成は最大 10 枠です。必要なら 2 回以上に分けます(上限は設定で 1〜3 回)。
- 合成費用は `(160 + 合成前の Lv × 40) × 素材の数` です。
- 在庫は管理しません。素材の候補は、経験値ユニットと聖霊(入手しやすいもの)です。
- 余りが同じ組み合わせが複数あるときは、合成回数、ゴールドの順で選びます。さらに同じなら余りの少ないものを選びます。
- 候補が非常に多い場合、ゴールドの比較は先頭 20,000 件までです。

#### 覚醒をまたぐ持ち越し

ゴールド、プラチナ、サファイアは、第一覚醒の上限 Lv を超えて得た経験値が、第二覚醒に持ち越されます。ブラックは持ち越されません。「覚醒の持ち越しを余りに数えない」設定(既定でオン)がオンで、第一覚醒の上限 Lv を目標にしたときだけ、持ち越される分を余りに数えません。

### 必ず使う素材の指定

- 聖霊や経験値ユニット、ドロップユニット(レアリティ、性別、クラス区分、Lv、同クラスの有無)を指定できます。
- 指定した素材が先に枠を占有し、残りの枠で最適化します。
- 指定した素材だけで目標を超える場合は、余りを表示し、ほかの素材は使いません。
- 指定した素材が 10 枠を超える場合はエラーにします(分割しません)。
- 素材の候補を絞り込む指定(禁止リスト)はありません。

### 端数の逆引き

経験値ユニットと聖霊だけで、必要量を超えない最大の組み合わせ(1 枠空けておく)を作ります。足りない端数を、ドロップユニット 1 体で埋めるときの条件を、余りの少ない順に最大 30 件出します。条件は、レアリティ、性別、クラス区分、Lv、同クラスボーナスの有無です。同クラスの有無は別々の候補として出します。

### 餌ユニットの育成オプション(既定はオフ)

ドロップした同キャラのユニットを、素材にする前に少しレベル上げした方が得か、を計算します。

```
正味の増加 = (Lv を上げた餌の経験値) - (Lv1 の餌の経験値) - (餌を Lv まで上げる累計経験値)
```

- 正味の増加が正のときだけ提案します。
- 提案するときは、餌を Lv1 のまま使う場合との差を一覧で出します。最適な Lv は 1〜40 から自動で探します。

### 設定

- 育成聖霊サリエット(合成経験値 +10%)の有無
- 基本 EXP アップ期間(Wiki の「基本EXPアップ時」の表の値を使います)
- 合成回数の上限
- 覚醒の持ち越しを余りに数えるか

設定と入力は、ブラウザの `localStorage` に保存します。

### 経験値の計算

```
合成 EXP = 基本 EXP + 同クラスボーナス + (素材 Lv - 1) × クラス区分の加算
```

- クラス区分の加算: ブロンズ以下 +5、ちびユニット +56、覚醒前 +160、覚醒後 +400
- サリエットありの場合は、合計に 1.1 を掛けて、小数点以下を切り捨てます。切り捨てかどうかは Wiki に明記がないため、Wiki の例(20,000 → 22,000 など、すべて割り切れる値)で確認できる範囲の仮定です。
- 聖霊や鎧のような固定経験値の素材には、Wiki の表のとおり、同クラスボーナスも Lv の加算もありません。

## 技術

TypeScript、React、Vite の静的サイトです。サーバーは使いません。PWA に対応していて、オフラインでも動きます。新しい版があるときは、再読み込みを促す表示が出ます。

```
npm install
npm run dev     # 開発サーバー
npm run test    # テスト(Vitest)
npm run build   # 型検査とビルド
```

- `src/core/`: 計算ロジック(UI に依存しない)
- `src/data/`: Wiki から取った数値データ
- `src/ui/`: 画面

## 公開

GitHub Pages で配信します。`main` に push すると、`.github/workflows/deploy.yml` がビルドして公開します。リポジトリは public にします。リポジトリ名を変える場合は、`vite.config.ts` の `base` も合わせて変えてください。

## Wiki との食い違い

- 「経験値」ページの合成早見表の「Lv80～ Lv99へ」(ゴールド)は 54,171 とありますが、同じページの累計経験値の表(Lv80 は 69,333、Lv99 は 126,504)から計算すると 57,171 です。このアプリは累計経験値の表を使います。プラチナ(28,901)とサファイア(46,620)の同じ欄は、表と一致しています。
